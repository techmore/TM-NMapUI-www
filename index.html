Installation

Get up and running in under 2 minutes

Clone from GitHub, install dependencies, and start scanning. It's that simple.

1

Clone the Repository

git clone https://github.com/techmore/TM-NmapUI.git
cd TM-NmapUI
2

Install Brew

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/
Homebrew/install/HEAD/install.sh)"
3

Run Install Script

./install.sh --no-daemon
4

Launch NMapUI

./start.sh
5

Open the dashboard

open http://127.0.0.1:9000
View on GitHub

System Requirements

Python 3.11+ and xsltproc
Nmap 7.80+ installed
macOS or Ubuntu scanner host
4GB RAM minimum
Network access to target ranges

Pro tip: Run with sudo for SYN scans and OS detection features.
